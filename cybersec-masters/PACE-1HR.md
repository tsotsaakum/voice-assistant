# 1-hour-per-day pacing guide

You have **60 minutes/day**. Do not compress the 8-week syllabus into calendar weeks. Use **~26 study days** (~one month if daily; ~two months if 3–4 days/week).

## Daily ritual (60 minutes)

| Minutes | Activity |
| --- | --- |
| 0–5 | Open yesterday’s 5-line note; recall one definition |
| 5–45 | Today’s single todo (read **or** lab **or** write — not all three) |
| 45–55 | Exit ticket / bullets in `notes/` |
| 55–60 | Mark todo done; peek at tomorrow’s title only |

**Rule:** If a task overruns, stop at 60. Split it — never “catch up” by skipping ethics.

## Calendar shape

- **Days 1–5:** Foundations + Lab 01 + Scholar skim  
- **Days 6–9:** Ethics + Assessment A1  
- **Days 10–13:** Crypto + network defense lab  
- **Days 14–16:** AppSec + Python defensive lab  
- **Days 17–20:** Pentest profession + Assessment A2  
- **Days 21–23:** Detection/IR + log triage  
- **Days 24–26:** Career + Assessment A3  

## After the core track

Optional **2–3 sessions/week**: 40 min authorized practice (TryHackMe/HTB/own VM) + 20 min remediation/portfolio note. Still no unauthorized testing.
