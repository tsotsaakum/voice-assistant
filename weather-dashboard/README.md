# Weather dashboard

A liquid-glass weather dashboard that runs on its own. It does not replace the Lentswe voice assistant.

Search uses the [Open-Meteo](https://open-meteo.com/) geocoding and forecast APIs. No API key.

## Run

```bash
cd weather-dashboard
npm install
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).

```bash
npm run build
npm run preview
```
